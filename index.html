The Problem

🔊 Noisy Signals

Portable EEG devices suffer from motion artifacts, powerline interference, and environmental noise—making diagnosis unreliable

⏱️ Processing Time

Traditional denoising methods are slow and resource-intensive, limiting real-time clinical use

📊 Data Loss

Aggressive filtering destroys diagnostic information while removing noise

The Solution

ABNC Algorithm

ABNC combines three techniques:

  1. Bandpass Filter (1-4 Hz) — Isolates diagnostic slow-wave frequencies
  2. Notch Filter (50 Hz) — Removes powerline interference
  3. Adaptive Wiener Filter — Suppresses broadband noise while maintaining signal structure

Result: Removes noise while preserving the diagnostic information needed for early dementia detection.

Technical Details

Algorithm Architecture

Cleaned Signal = 0.7 × BandPass(1-4 Hz) + 0.3 × WienerFilter(Corrupted)

Where:
  • BandPass(1-4 Hz)  → Isolates diagnostic slow-waves (delta band)
  • WienerFilter      → Adaptive noise suppression
  • Weights           → Optimized for frequency preservation + noise removal

Validation Details

  • Dataset: 100 test samples, 4-channel EEG
  • Sampling rate: 250 Hz (standard for clinical EEG)
  • Duration: 64 seconds per recording
  • Noise sources: Motion artifacts (1-2 Hz), 50 Hz powerline, white noise
  • Metric: SNR computed as 10×log₁₀(Signal Power / Noise Power)
